## Organización por grupo funcional

Cada sección o grupo funcional implementado debe tener su propia carpeta en `docs/`, con un `README.md` y documentos de historias de usuario identificados de forma estable. Los criterios se escriben siempre en español con el formato **Dado – Cuando – Entonces**. El grupo transversal se llama `system`.
